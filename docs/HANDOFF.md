# Перекраска демо под конкретного клиента

Инструкция по превращению демо в сайт конкретной компании. Цель — **40 минут без правок кода**.
Если для замены контента понадобилось открыть файл в `components/` — это ошибка архитектуры,
а не задача исполнителя: недостающее поле добавляется в `content/types.ts`.

---

## Что меняется (и только это)

| Шаг | Где | Что делаем |
| --- | --- | --- |
| 1 | `content/site.config.ts` → `company` | название, юрлицо, ИНН, телефон, мессенджеры, адрес, география, часы работы |
| 2 | `content/site.config.ts` → `brand.accent` | фирменный цвет клиента — **одна строка**, весь сайт перекрашивается |
| 3 | `public/media/<client-slug>/` | фотографии клиента; путь прописывается в `brand.photoDir` |
| 4 | `content/site.config.ts` → `hero`, `products`, `cases` | оффер, каталог решений, реальные объекты с параметрами и ценами |
| 5 | `content/site.config.ts` → `trust`, `reviews`, `faq` | факты компании, отзывы со ссылками, ответы на возражения |
| 6 | `content/pricing.ts` | прайс клиента: цена за метр, коэффициенты высоты, цены ворот и автоматики |
| 7 | `content/site.config.ts` → `isDemo: false` | снимает демо-пометки со страницы и правовых документов |
| 8 | `content/site.config.ts` → `legal` + `app/privacy`, `app/consent` | документы юрлица клиента вместо шаблонных |
| 9 | `.env` | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `NEXT_PUBLIC_YM_ID`, `NEXT_PUBLIC_SITE_URL` |

### Несколько получателей заявок

`TELEGRAM_CHAT_ID` принимает список через запятую — заявка уходит каждому:

```
TELEGRAM_CHAT_ID=123456789,987654321
```

Свой id человек узнаёт у `@userinfobot`. Отрицательный id — это группа, она
тоже работает как получатель. Каждый получатель должен один раз нажать Start
у бота: боты не пишут первыми тому, кто с ними не заговорил.

Если один получатель заблокировал бота или не нажал Start, остальные заявку
всё равно получают, а отказ пишется в лог с указанием конкретного чата.

## Правила, которые нельзя нарушать

**Один акцентный цвет.** В палитре ровно один акцент, и он занят кнопкой «Рассчитать стоимость».
Если клиент просит «добавить ещё зелёный и синий» — объясняем: второй акцент отбирает внимание
у главной кнопки, и конверсия падает. Фирменные цвета живут в логотипе, а не в интерфейсе.

**Ни одной недоказанной цифры.** Поля `trust.years`, `objects`, `crews`, `warrantyYears` имеют
тип `Fact = number | '[X]'`. Пока клиент не подтвердил цифру — остаётся `'[X]'`. Выдуманные
«15 лет на рынке» на сайте компании, работающей три года, — это репутационный риск клиента,
который он заметит не сразу, но заметит.

**Отзыв без ссылки не публикуется.** Поле `Review.url` обязательное по типу: собрать проект
с отзывом без источника физически нельзя. Берём реальные отзывы с Яндекс Карт или 2ГИС.

**Не обещаем за клиента.** `trust.contract` и `trust.production` — булевы флаги. Если компания
не фиксирует смету договором, флаг `false`, и блок с обещанием просто не рендерится. Не пишем
«фиксируем цену», если клиент так не работает.

**Фото — только реальные объекты.** Крупные кадры готового результата: забор, дом, участок.
Не металл макро, не стоковые бригады в касках. Если у клиента нет фото — это первое, что нужно
у него запросить: без них демо не отличается от шаблона.

## Проверка перед отправкой клиенту

Прогнать перед сдачей:

```bash
npm run typecheck   # контентная модель собирается без ошибок
npm run lint
npm run build
```

Дальше — глазами:

- [ ] `[X]` не осталось нигде, кроме мест, где клиент действительно не дал цифру
- [ ] телефон кликабелен и ведёт на реальный номер, мессенджеры открываются
- [ ] тестовая заявка из квиза дошла в Telegram владельца
- [ ] все ссылки на отзывы открывают оригинал
- [ ] `isDemo: false`, демо-пометки исчезли
- [ ] реквизиты и правовые страницы — от юрлица клиента
- [ ] проверено на реальном телефоне, sticky-панель не перекрывает контент

## Структура фотографий

```
public/media/<client-slug>/
├─ hero.jpg                  # первый экран, 16:9, объект целиком
├─ product-<slug>.jpg        # карточки каталога, 4:3
├─ case-<n>-<m>.jpg          # кейсы, 3:2, по 3–5 фото на объект
└─ owner.jpg                 # владелец или команда (опционально, но сильно работает)
```

Единая обработка всей серии: слегка приглушённая насыщенность, холодные тени. Разные съёмки
клиента должны выглядеть одним материалом, иначе страница рассыпается визуально.
