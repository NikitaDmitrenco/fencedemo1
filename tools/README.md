# Инструменты

## `build.mjs` — генератор изображений-заглушек

Создаёт демонстрационные изображения в `public/media/demo/`: тёмные панели
с фактурой конкретного материала (профнастил, евроштакетник, 3D-сетка,
жалюзи, откатные ворота).

```bash
node tools/build.mjs
```

Это **не** имитация фотографий: попытка нарисовать «почти фото» читается как
дешёвый рисунок и роняет доверие ко всей странице. Заглушки честнее выглядят
намеренными.

При подготовке сайта под клиента скрипт не нужен — реальные снимки объектов
кладутся в `public/media/<client-slug>/` с теми же именами файлов, а путь
меняется в `brand.photoDir` (см. `docs/HANDOFF.md`).
