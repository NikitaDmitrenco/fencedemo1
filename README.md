# Fence Demo — демо-сайт для ниши «Заборы и ворота»

Универсальный одностраничный демо-сайт, который можно отправлять владельцам компаний по установке
заборов, ворот и металлоконструкций в любом регионе. Формат: **«Так мог бы выглядеть ваш сайт»**.

Продукт построен как **сайт-конструктор**: один код — любой клиент. Замена под нового заказчика =
правка одного конфиг-файла, папка с фотографиями и один акцентный цвет.

## Ключевые принципы

- Главный CTA на всей странице — **«Рассчитать стоимость»**, а не «Оставить заявку».
- Одна длинная страница ведёт от первого интереса к предварительному расчёту без изучения меню.
- Mobile-first: основной локальный спрос приходит со смартфона.
- Графит / молочный / металл + **ровно один** акцентный цвет.
- Ни одной недоказанной цифры: в демо — `[X]`, отзывы только со ссылкой на оригинал.

```bash

npm run dev        # http://localhost:3000
npm run build      # продакшн-сборка
npm run typecheck  # проверка контентной модели
npm run lint
```

Переменные окружения — см. `.env.example`.

| Показатель | Демо | Боевой режим |
|---|---|---|

| Accessibility | 100 | 100 |
| Best Practices | 100 | 100 |
| SEO | 66¹ | 100 |
| CLS | 0 | 0 |
| Total Blocking Time | 60 мс | 60 мс |
| Largest Contentful Paint | 2,8 с² | 2,8 с² |

¹ Демо намеренно закрыто от индексации: сайт с вымышленными названием,
телефоном и реквизитами не должен попадать в выдачу как настоящая компания.
При `isDemo: false` обход открывается и показатель — 100.

² Бюджет плана — 2,0 с. LCP здесь текстовый: заголовок перерисовывается,
когда догружается веб-шрифт (53 КБ). Профиль Lighthouse нарочно пессимистичен
(1,6 Мбит/с, замедление процессора ×4).

### Расхождения с бюджетами плана

| Показатель | Бюджет §7 | Факт | Причина |
|---|---|---|---|
| LCP | ≤ 2,0 с | 2,8 с | текстовый LCP перерисовывается при загрузке веб-шрифта |
| JS первого экрана | ≤ 120 КБ gzip | 154 КБ | из них ~114 КБ — сам React и рантайм Next; это пол стека, а не наш код |

Оба бюджета оказались оптимистичными при выбранном стеке. На пользовательском
опыте это не сказалось: Performance 96, TBT 60 мс, CLS 0. Сокращение потребовало
бы отказа от веб-шрифта и смены фреймворка — цена выше выгоды для этой задачи.

## Критерий готовности

Если собственнику можно отправить ссылку без поясняющей презентации, и за 30–60 секунд он понимает,
что его компания могла бы выглядеть так же — задача выполнена.
